## 怎么使用

### 方法一：直接下载（推荐）

1. 点击上方文件名进入文件页面
2. 点击右侧 **`Download`**（下载）按钮
3. 保存到电脑或 U 盘
4. **双击文件**，浏览器自动打开，即可使用

### 方法二：整包下载

1. 点击本页绿色 **`Code`** 按钮 → **`Download ZIP`**
2. 解压后得到全部工具

### 方法三：保存到 U 盘

下载好的 HTML 文件拷贝进 U 盘，插到教室电脑上双击即可——**断网也能用**。

## 这些工具是怎么来的？

全部由 AI 编程工具 **TRAE**（字节跳动出品，[trae.cn](https://www.trae.cn/)）生成：

> 老师用一句大白话描述需求 → AI 自动写出完整网页 → 老师下载保存 → 双击使用

以点名器为例，给 AI 的原话是：

```
帮我做一个课堂随机点名器网页：
①可以粘贴全班学生姓名，先放一份 40 人示例名单；
②一个大按钮，点击后姓名快速滚动，停下抽出一位，带动画和音效；
③能记录已抽过的同学，支持"不重复抽取"开关；
④界面适合投影，字号要大；
⑤做成单个 HTML 文件，保存后双击就能用，不需要联网。
```

**您不写一行代码**——就像给裁缝店下订单："我要一件这样的衣服"，AI 把它做出来。

## 想要自己的工具？

1. 到 [trae.cn](https://www.trae.cn/) 下载安装 TRAE（免费）
2. 把上面那段"需求描述"改成您自己的需求（例如：值日表轮换器、限时计时器、公式演示页……）
3. 发给 TRAE，等几分钟，您的工具就做好了
